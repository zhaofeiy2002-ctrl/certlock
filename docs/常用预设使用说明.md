# CertLock 2.1.2 常用预设

新增列表搜索、复制指纹/路径、横向滚动和备份目录入口，封禁与保留规则沿用 v2.1.1。刷新时会保留仍然可见的选中项；被搜索隐藏的项不能继续通过按钮操作。

可用 `Ctrl+F` 定位搜索、`Esc` 清空搜索、列表内 `Ctrl+C` 复制、`F5` 刷新。右键可复制整条规则。“打开备份目录”优先打开本次运行最近保存的备份所在目录，否则定位自动备份目录；不存在时仅提示。

便携发行包，适用 Windows 10/11 64 位，包含单文件程序和 JSON 预设，不需要安装 Python，不常驻后台。

v2.1.1 打开界面不再自动修改旧策略。读取策略失败会停止操作；证书按签名者标识匹配，无法确定或不支持的多重签名会拒绝，不猜测。新建哈希封禁仍未启用，不要通过提升权限反复尝试。

提取支持 EXE/DLL 中的单个嵌入式签名，不支持 MSI、Catalog、多签名或嵌套签名。提取证书不是签名与信任链有效性认证。列表表示已配置规则，实际拦截须在目标系统验证。

## 三步配置

1. 解压后以管理员身份运行 `CertLock.exe`，点击“常用预设（保留 WPS）”。
2. 勾选要封禁的证书范围。WPS 自动检测；若还要保留 QQ、腾讯视频等，点“添加保留程序”选择对应 EXE。绿色版 WPS 或特殊安装位置可点“手动指定 WPS”。
3. 点击“预览与导入”，核对添加、跳过、过期证书提示后确认。注销或重启，在目标电脑检查拦截情况与保留软件是否正常。

“导入模板”也能读取随包的 `常用预设-保留WPS.json`。保护字段从 v2.1.0 开始提供，当前版本包含 v2.1.1 的安全修复；更早版本会忽略 WPS 保护逻辑。

## 覆盖范围

候选包含 360、2345、鲁大师、腾讯共享签名，以及两张金山安全证书，共六张。只针对这些证书签名的文件，不等于所有同名软件、最新版本或所有不需要的软件。

2026-10-07 本地证书检查：360、2345、金山安全证书 1 已过期，仍保留为历史签名规则候选；不能据此宣称可覆盖厂商换证后的版本。可通过原有“封禁新证书”从实际安装包提取新签名，再导出新的模板。

## 保留规则

- 自动定位 WPS 后读取安装目录内 EXE/DLL 的嵌入签名。任一封禁证书与保留签名相同，则整条封禁候选跳过。
- 找不到 WPS 时跳过全部金山证书；不承诺此时能封禁金山毒霸或驱动精灵。
- 对保留的其他软件，也按所选文件的签名跳过对应证书。需要保留辅助组件时，可一并选择它们的 EXE/DLL。
- 同一签名同时用于两个产品时，证书规则无法只保留其中一个又封禁另一个。腾讯共享证书可能同时覆盖 QQ、腾讯视频，不能当成电脑管家专用。
- 检查到现有证书禁止规则已与保留软件签名冲突时停止导入；不会替用户自动移除已有规则。
- 本工具核对本次模板与可读取的嵌入签名，不保证覆盖域策略、AppLocker、其他哈希规则或未来换证升级的影响。

## 模板分发

可以把勾选的候选导出为新的 JSON。导出文件不包含本机保留文件路径；接收者的 WPS 会自动重新检测，其他保留软件由接收者选择。不向网上上传证书、文件或路径。

## 备份与恢复

导入前在 `%LOCALAPPDATA%\CertLock\backups` 生成独立 JSON 证书策略备份。无法保存备份时不写规则。它不是完整系统镜像或证书存储备份。

证书写入沿用 v2 的实现，包含向本机 TrustedPublisher（受信任的发布者）证书存储导入签名证书。移除 SRP 封禁规则不会自动移除该存储中的证书，不应把规则 JSON 备份称为完整系统回滚。

若需撤销本次导入，在规则列表按预览中的指纹移除本次新增规则；不要移除原来已有的规则。备份里的 `planned_additions` 是计划清单，不代表每条都成功写入，以实际导入结果为准。部分失败会明确显示。

## 规则优先级

微软记录的 SRP 优先级：哈希 > 证书 > 路径 > 区域 > 默认。给 WPS 添加路径允许规则无法覆盖证书禁止，故本预设使用签名排除。

来源：[微软 SRP 排错与优先级](https://learn.microsoft.com/en-us/troubleshoot/windows-server/group-policy/troubleshoot-software-restriction-policies)、[微软 SRP 规则管理](https://learn.microsoft.com/en-us/windows-server/identity/software-restriction-policies/work-with-software-restriction-policies-rules)。

## 验证边界

开发阶段通过模拟注册表与文件签名的回归测试、只读预览、打包检查。没有在开发者日常电脑实际增加封禁规则；注销后实际阻止运行的效果需在对方电脑或隔离 Windows 环境验收。
