# CertLock v2.1.1

修复 v2.1.0 功能核查发现的策略安全与证书识别问题，保留现有界面和主题。Windows x64 便携包，不需要安装 Python。

## 本次修复

- 打开 GUI 不再自动修改旧规则和默认安全级别。
- 按 PKCS#7 签名者标识匹配证书，不再按证书长度和厂商名称猜测。
- 现有证书策略读取不完整时停止规划/导入，不生成虚假的空备份。
- 新建哈希封禁仍未提供，明确说明功能限制，不误报管理员权限。
- 修正状态表述，区分“已配置规则”和“已验证拦截”。

## 使用与限制

解压 ZIP 后运行 `CertLock.exe`，写入规则需要管理员权限。常用预设支持勾选、WPS 核对和额外保留程序；确认预览后再导入。未定位 WPS 时保守跳过金山候选。

签名提取支持单个嵌入式签名的 EXE/DLL；多签名、嵌套签名、歧义或缺失签名者会拒绝，MSI 和 Catalog 签名不在支持范围。提取证书不是完整签名/信任链验证。

内置证书是有限的历史候选，不覆盖厂商换证后的所有版本。备份不是完整系统镜像，也不完整回滚 TrustedPublisher。SRP 实际拦截及 WPS 的完整可用性仍须在隔离或明确授权的目标 Windows 中验收；本版本未在开发者日常电脑真实施加封禁。

## 验证

发布流程运行全部单元测试、原生 Tk 控件检查、PyInstaller 构建及真实冻结 EXE 的预设导出、错误处理和签名解析测试。ZIP 附使用说明、预设、许可及文件校验值，Release 另附 ZIP 的 SHA-256。

v2.1.0 的历史资产不覆盖。推荐升级，不能将修复发布等同于所有系统的拦截效果保证。
