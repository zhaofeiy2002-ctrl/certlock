# CertLock v2.1.0：常用预设与保留软件

Windows 10/11 64 位便携版。下载 `CertLock_v2.1.0-portable.zip`，解压后运行 `CertLock.exe`。

## 本次更新

- 增加“常用预设（保留 WPS）”：勾选要封禁的签名范围，再预览导入。
- 自动从注册信息及常见安装目录寻找 WPS，核对 EXE/DLL 的嵌入签名；未能定位时保守跳过金山证书。
- 支持添加其他保留程序，例如 QQ；冲突的签名证书会整条跳过。
- 支持导出勾选的模板，在其他电脑重新适配，不把本机保留文件路径写入模板。
- 模板先全量校验再写入，导入前备份证书策略，明确报告跳过和失败。
- 修复证书过期检查，并纠正 SRP 证书与路径规则的优先级说明。

## 使用

1. 以管理员身份运行，点击“常用预设（保留 WPS）”。
2. 勾选封禁项；需要保留其他软件时，选择它们的 EXE/DLL。
3. 查看预览中的添加、跳过及过期提示，确认后导入。
4. 注销或重启，在目标电脑验证拦截效果和保留软件可用性。

也可通过“导入模板”读取 ZIP 内的 `常用预设-保留WPS.json`。该保护模板需使用 v2.1.0 或支持其保护字段的新版本，旧版不识别保护字段。

## 范围与验证

- 内置六张候选证书，并非自动识别或封禁所有不需要的软件。厂商换证后需更新规则。
- 部分内置证书已过期，保留用于历史签名范围提示，不保证覆盖当前版本。
- 同一证书签名的不同产品不能靠证书规则精确区分；腾讯共享签名可能同时影响 QQ、腾讯视频。
- 18 项回归测试、原生 Tk 界面检查和打包 exe 导出检查已通过。未在开发者日常电脑真实施加封禁，实际 SRP 执行效果需在目标或隔离 Windows 环境验收。
- 策略 JSON 备份不是完整系统镜像，也不包含 TrustedPublisher 证书存储的完整回滚。

包内含使用说明、JSON 预设和 SHA-256 校验文件；Release 另附 ZIP 校验值。
