# CertLock v2.1.2：操作便利性改进

本版以易用性优化为主，沿用 v2.1.1 的底层策略与签名解析逻辑，保留原有界面主题和操作确认。

## 本次改进

- 规则列表支持按描述、指纹、路径或状态搜索，并显示匹配数量。
- 支持复制完整指纹或路径，右键可复制整条规则；长内容支持横向滚动。
- 刷新后保留仍有效且可见的选中项和滚动位置。被搜索隐藏的项自动取消选择，避免误操作。
- 增加备份目录入口，方便找到自动备份或本次运行最近保存的手动备份。
- 调整紧凑窗口布局，保留状态栏和操作按钮，支持原有深浅主题。

## 下载与使用

下载本页附件 `CertLock_v2.1.2-portable.zip`，解压后运行 `CertLock.exe`，无需安装 Python。写入系统策略需要管理员权限。

`Ctrl+F` 定位搜索；搜索框内 `Esc` 清空；列表内 `Ctrl+C` 复制选中指纹或路径；`F5` 刷新。

## 验证与边界

开发阶段通过 39 项原有单元测试、原生 Tk 易用性检查以及冻结 EXE 检查，并比对确认 55 个顶层后端函数与 v2.1.1 一致。浅色和深色主题在 820×700、760×640 两种窗口尺寸下完成检查，不代表所有 DPI 和屏幕均已验收。

本版没有新增哈希封禁能力，不更换规则引擎；多签名与嵌套签名仍采取保守拒绝。实际 Windows 拦截、撤销和保留软件完整可用性，仍需在隔离或明确授权的目标环境验收。规则显示为已配置，不等于已证明拦截成功。

备份不是完整系统镜像，不能完整回滚 TrustedPublisher。历史版本资产保留，不通过覆盖旧版本发布本次更新。

附件同时提供 ZIP 的 SHA-256，包内另含文件校验清单、使用说明和许可。
